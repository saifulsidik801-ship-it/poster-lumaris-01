LUMARIS — a travel poster for a place that isn't there. A coastal town where the lighthouse is a living tree: its trunk a tower, its branches hung with lanterns, its beacon shining over a turquoise sea at dusk. The place name is set huge in cream serif capitals across the top, with the subtitle THE LIGHTHOUSE THAT GROWS beneath it. A make.fun entry.

## Run it

```sh
python3 main.py
```

Writes the poster to `/output/entry.png` (1024x1024 JPEG, under 1 MiB).
